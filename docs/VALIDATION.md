## CI configuration

The [workflow](../.github/workflows/ci.yml) runs `npm test` on pull requests, pushes to `main` and manual dispatch across Ubuntu and macOS with Node.js 20, 22 and 24. Jobs have read-only contents permission and a 10-minute timeout; superseded runs are cancelled and one failing combination does not cancel the others. Actions are pinned to commit SHAs, checkout credentials are not persisted, and Node.js, npm and Git versions are logged. CI uses mock provider protocols, fake provider executables and real Git/test subprocesses; it makes no model calls, uploads no artifacts and never merges. A passing run is bounded test evidence, separate from live-provider qualification, task verification and human acceptance.
