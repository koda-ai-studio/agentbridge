# Reporting a vulnerability

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for them.

Include what you ran, what happened, and the AgentBridge version (`agentbridge --version`). We aim to acknowledge reports within a week.

What AgentBridge does and does not protect against is described in [docs/SECURITY.md](docs/SECURITY.md). Reports that a determined local user or agent with write access to the records can alter them are expected behavior unless they bypass a documented check, such as signed approval verification.
